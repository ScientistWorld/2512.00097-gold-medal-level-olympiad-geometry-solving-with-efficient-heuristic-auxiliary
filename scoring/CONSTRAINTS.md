# Scientist Constraints

Future methods should improve valid solve rates without changing the task.

## Fixed Inputs

Use the provided JSONL benchmark files generated by `data/prepare_benchmarks.py`. Do not edit premises, conclusions, problem IDs, or difficulty metadata.

## Fixed Evaluator

`scripts/evaluate.sh` must remain method-agnostic and must read solver output artifacts from `outputs/*.jsonl`. Evaluation code must not import from `method/`.

## Resource Scope

Evaluation is CPU-only and non-neural. Do not use GPU inference, LLM calls, online services, or neural proposal models during scored runs.

## Search Budget

Report and preserve the configured attempt count, auxiliary rounds, timeout, and seed. Solves found outside the declared budget should not be counted.

## Output Format

Solver outputs must be JSONL rows containing at least `problem_id`, `solved`, `status`, `seconds`, and `auxiliary_clauses`. Additional fields are allowed if the evaluator ignores them.
